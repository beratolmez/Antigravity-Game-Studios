# Claude Code Game Studios — Antigravity Workspace Rules

This workspace uses the Claude Code Game Studios (CCGS) architecture integrated into Antigravity.
- Master rules and protocol: see `CLAUDE.md`, `.claude/docs/coordination-rules.md`, and `.claude/docs/directory-structure.md`.
- 49 Studio Agents: defined in `.claude/agents/<agent-name>.md` (and `.agents/agents/<agent-name>.md`), coordinated via `.claude/docs/agent-roster.md`.
- 78 Studio Skills: registered via `.agents/skills.json` pointing to `.claude/skills/<skill-name>/SKILL.md`.
- Document Templates: located in `.claude/docs/templates/`.
- Directory-specific rules: see `design/CLAUDE.md`, `docs/CLAUDE.md`, `src/CLAUDE.md`, and `.claude/rules/`.
